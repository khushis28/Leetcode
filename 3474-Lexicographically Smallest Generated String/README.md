<h2><a href="https://leetcode.com/problems/lexicographically-smallest-generated-string">3474. Lexicographically Smallest Generated String</a></h2><h3>Hard</h3><hr>

<p>You are given two strings, <code>str1</code> and <code>str2</code>, of lengths <code>n</code> and <code>m</code>, respectively.</p>

<p>A string <code>word</code> of length <code>n + m - 1</code> is said to be generated by <code>str1</code> and <code>str2</code> if for every index <code>0 &lt;= i &lt;= n - 1</code>:</p>

<ul>
<li>If <code>str1[i] == 'T'</code>, then the substring of <code>word</code> of length <code>m</code> starting at index <code>i</code> must be exactly equal to <code>str2</code>, that is, <code>word[i..i+m-1] == str2</code>.</li>
<li>If <code>str1[i] == 'F'</code>, then the substring of <code>word</code> of length <code>m</code> starting at index <code>i</code> must <strong>not</strong> be equal to <code>str2</code>, that is, <code>word[i..i+m-1] != str2</code>.</li>
</ul>

<p>Return the <strong>lexicographically smallest</strong> string that can be generated. If no valid string exists, return an empty string <code>""</code>.</p>

<p>&nbsp;</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
str1 = "TFTF", str2 = "ab"

<strong>Output:</strong>
"ababa"

<strong>Explanation:</strong>
The string "ababa" satisfies all conditions:

Index 0 → 'T' → substring "ab" matches str2  
Index 1 → 'F' → substring "ba" does not match str2  
Index 2 → 'T' → substring "ab" matches str2  
Index 3 → 'F' → substring "ba" does not match str2  

Both "ababa" and "ababb" are valid, but "ababa" is lexicographically smaller.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong>
str1 = "TFTF", str2 = "abc"

<strong>Output:</strong>
""

<strong>Explanation:</strong>
No string of length n + m - 1 can satisfy all required conditions.
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre>
<strong>Input:</strong>
str1 = "F", str2 = "d"

<strong>Output:</strong>
"a"

<strong>Explanation:</strong>
The only substring of length 1 must not be "d".  
The lexicographically smallest valid choice is "a".
</pre>

<p>&nbsp;</p>

<p><strong>Constraints:</strong></p>

<ul>
<li><code>1 &lt;= n == str1.length &lt;= 10<sup>4</sup></code></li>
<li><code>1 &lt;= m == str2.length &lt;= 500</code></li>
<li><code>str1</code> consists only of <code>'T'</code> or <code>'F'</code></li>
<li><code>str2</code> consists only of lowercase English letters</li>
</ul>
