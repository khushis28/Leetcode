<h2><a href="https://leetcode.com/problems/complement-of-base-10-integer">1009. Complement of Base 10 Integer</a></h2><h3>Easy</h3><hr>

<p>The <strong>complement</strong> of an integer is obtained by flipping all bits in its binary representation — changing every <code>0</code> to <code>1</code> and every <code>1</code> to <code>0</code>.</p>

<p>For example, the number <code>5</code> is <code>"101"</code> in binary. Its complement becomes <code>"010"</code>, which equals <code>2</code> in decimal.</p>

<p>Given an integer <code>n</code>, return its complement.</p>

<p>&nbsp;</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
n = 5

<strong>Output:</strong>
2

<strong>Explanation:</strong>
Binary of 5 → "101"  
Complement → "010" → 2
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong>
n = 7

<strong>Output:</strong>
0

<strong>Explanation:</strong>
Binary of 7 → "111"  
Complement → "000" → 0
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre>
<strong>Input:</strong>
n = 10

<strong>Output:</strong>
5

<strong>Explanation:</strong>
Binary of 10 → "1010"  
Complement → "0101" → 5
</pre>

<p>&nbsp;</p>

<p><strong>Constraints:</strong></p>

<ul>
<li><code>0 ≤ n &lt; 10<sup>9</sup></code></li>
</ul>

<p><strong>Note:</strong> This problem is the same as <a href="https://leetcode.com/problems/number-complement/">476. Number Complement</a>.</p>
